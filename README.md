# WalletOS — راهنمای انتشار روی Netlify

## ساختار فایل‌ها
```
walletos-pwa/
├── index.html          ← خود اپلیکیشن
├── manifest.json        ← تنظیمات نصب PWA
├── sw.js                ← Service Worker (کش/آفلاین)
├── _headers              ← تنظیمات کش نتلیفای
├── netlify.toml           ← تنظیمات دیپلوی
└── icons/                ← آیکون‌های اپ
```

## روش ۱: درگ‌اند‌دراپ (ساده‌ترین راه، بدون نیاز به نصب چیزی)

1. برو به [app.netlify.com/drop](https://app.netlify.com/drop)
2. کل پوشه‌ی `walletos-pwa` رو (نه فایل‌های تکی، خود پوشه رو) بکش و بنداز توی صفحه
3. چند ثانیه صبر کن — نتلیفای یه آدرس مثل `random-name-123.netlify.app` بهت میده
4. تمومه! الان سایتت آنلاینه با HTTPS (که برای نصب PWA لازمه)

> نکته: اگه خواستی آدرس رو عوض کنی، از پنل نتلیفای برو به Site settings → Change site name

## روش ۲: از طریق گیت‌هاب (برای آپدیت‌های بعدی راحت‌تره)

1. این پوشه رو توی یه ریپوی گیت‌هاب آپلود کن
2. توی [app.netlify.com](https://app.netlify.com) → Add new site → Import from Git
3. ریپو رو انتخاب کن، فیلد Build command رو خالی بذار، Publish directory رو `.` بذار
4. Deploy بزن

## نصب اپ روی گوشی/کامپیوتر

- **اندروید (کروم):** وارد سایتت شو → یه نوار "افزودن به صفحه اصلی" پایین میاد → بزن Install
- **آیفون (سافاری):** وارد سایت شو → دکمه‌ی Share → Add to Home Screen
- **دسکتاپ (کروم/اج):** یه آیکون نصب کنار آدرس‌بار ظاهر میشه → بزن Install

## نکته‌ی مهم درباره‌ی آفلاین بودن

اپ از React، Recharts و Lucide از طریق CDN استفاده می‌کنه، پس:
- **بار اول** که باز میشه، به اینترنت نیاز داره
- Service Worker بعد از بار اول، این فایل‌ها رو کش می‌کنه، پس دفعات بعدی (حتی بدون اینترنت) کار می‌کنه
- دیتای خودت (تراکنش‌ها، بودجه، اهداف) از همون بار اول کاملاً لوکال و آفلاین توی IndexedDB مرورگرت ذخیره میشه و به اینترنت وابسته نیست

اگه بخوای صد در صد از بار اول هم بدون اینترنت کار کنه، باید یه نسخه‌ی بیلد‌شده (با ابزارهایی مثل Vite) بسازیم که همه‌چیز رو لوکال باندل می‌کنه — در صورت نیاز بگو تا اون نسخه رو هم بسازم.
